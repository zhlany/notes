### 1.工作池worker pool

创建一定数量的goroutine，从共享的管道中获取任务。
场景：显示并发数量，避免资源耗尽



### 2.Fan-Out/Fan-In

将多个协程从一个管道（fan-out）读取数据，处理后发送到另一个管道(fan-in)

场景：任务并行处理，后最总结果

```go
func producer(nums ...int) <-chan int {
    out := make(chan int)
    go func() {
        for _, n := range nums {
            out <- n
        }
        close(out)
    }()
    return out
}

func square(in <-chan int) <-chan int {
    out := make(chan int)
    go func() {
        for n := range in {
            out <- n * n
        }
        close(out)
    }()
    return out
}

func main() {
    in := producer(1, 2, 3, 4)
    //两个go同时处理同一个管道
    ch1 := square(in)
    ch2 := square(in)

    for n := range merge(ch1, ch2) {
        fmt.Println(n)
    }
}

//汇总管道
func merge(chs ...<-chan int) <-chan int {
    var wg sync.WaitGroup
    out := make(chan int)

    output := func(c <-chan int) {
        for n := range c {
            out <- n
        }
        wg.Done()
    }

    wg.Add(len(chs))
    for _, c := range chs {
        go output(c)
    }

    go func() {
        wg.Wait()
        close(out)
    }()
    return out
}
```

### 3. Pipeline（管道）

将多个go串联起来，每个go处理前面go的结果，并将此次结果传给下一个go

场景：多个步骤处理数据（平常逻辑写代码）

### 4.Select超时控制

超时控制，防止Goroutine无限期等待

场景：网络请求，任务执行

```go
func main() {
    ch := make(chan string)

    go func() {
        time.Sleep(2 * time.Second)
        ch <- "result"
    }()

    select {
    case res := <-ch:
        fmt.Println(res)
    case <-time.After(1 * time.Second):
        fmt.Println("timeout")
    }
}
```

### 5. 取消信号Done Channel

使用一个`done` channel来通知Goroutine停止执行

场景：手动取消go执行（）关闭管道

```go
func worker(done <-chan bool) {
    for {
        select {
        case <-done:
            fmt.Println("Worker stopped")
            return
        default:
            fmt.Println("Working...")
            time.Sleep(500 * time.Millisecond)
        }
    }
}

func main() {
    done := make(chan bool)
    go worker(done)

    time.Sleep(2 * time.Second)
    close(done)
    time.Sleep(1 * time.Second)
}
```

### 6.缓冲管道

带缓冲的channel来减少Goroutine之间的同步等待

场景：生产者和消费者速度不一致的场景

```go
func main() {
    ch := make(chan int, 2)

    ch <- 1
    ch <- 2

    fmt.Println(<-ch)
    fmt.Println(<-ch)
}
```

### 7.速率限制

使用`time.Tick`或`time.After`来控制Goroutine的执行速率

场景：于需要限制任务执行速率的场景，如API调用、资源访问等

```go
func main() {
    requests := make(chan int, 5)
    for i := 1; i <= 5; i++ {
        requests <- i
    }
    close(requests)

    limiter := time.Tick(200 * time.Millisecond)

    for req := range requests {
        <-limiter
        fmt.Println("Request", req, time.Now())
    }
}
```
