# 🎯 **Go fmt 占位符速查表（完整版）**

## 1️⃣ **通用占位符**

| 占位符 | 说明           | 示例                                         |
| ------ | -------------- | -------------------------------------------- |
| `%v`   | 默认格式       | `fmt.Printf("%v", 123)` → 123                |
| `%+v`  | 结构体带字段名 | `struct{X int}{1}` → `{X:1}`                 |
| `%#v`  | Go 语法表示    | `struct{X int}{1}` → `struct { X int }{X:1}` |
| `%T`   | 值的类型       | `fmt.Printf("%T", 123)` → int                |
| `%%`   | 输出 %         | `fmt.Printf("%%")` → %                       |

------

## 2️⃣ **布尔类型**

| 占位符 | 说明              | 示例                            |
| ------ | ----------------- | ------------------------------- |
| `%t`   | 输出 true / false | `fmt.Printf("%t", true)` → true |

------

## 3️⃣ **整数类型**

| 占位符 | 说明         | 示例           |
| ------ | ------------ | -------------- |
| `%b`   | 二进制       | 255 → 11111111 |
| `%c`   | Unicode 字符 | 65 → A         |
| `%d`   | 十进制       | 255 → 255      |
| `%o`   | 八进制       | 255 → 377      |
| `%x`   | 十六进制小写 | 255 → ff       |
| `%X`   | 十六进制大写 | 255 → FF       |
| `%U`   | Unicode 格式 | 65 → U+0041    |

------

## 4️⃣ **浮点数、复数**

| 占位符 | 说明                 | 示例                      |
| ------ | -------------------- | ------------------------- |
| `%b`   | 科学计数法二进制形式 | 3.14 → 70368744177664p-46 |
| `%e`   | 科学计数法 e 小写    | 3.14 → 3.140000e+00       |
| `%E`   | 科学计数法 E 大写    | 3.14 → 3.140000E+00       |
| `%f`   | 小数点形式           | 3.14 → 3.140000           |
| `%g`   | 自动选择 %f 或 %e    | 3.14 → 3.14               |
| `%G`   | 自动选择 %f 或 %E    | 3.14 → 3.14               |

------

## 5️⃣ **字符串和字节切片**

| 占位符 | 说明                        | 示例                |
| ------ | --------------------------- | ------------------- |
| `%s`   | 直接输出字符串或 byte slice | `"abc"` → abc       |
| `%q`   | 带双引号并转义              | `"abc"` → "abc"     |
| `%x`   | 每字节输出两位十六进制小写  | `"abc"` → 616263    |
| `%X`   | 每字节输出两位十六进制大写  | `"abc"` → 616263    |
| `%p`   | 指针地址（16 进制）         | `&s` → 0xc000010230 |

------

## 6️⃣ **指针**

| 占位符 | 说明     | 示例                                             |
| ------ | -------- | ------------------------------------------------ |
| `%p`   | 指针地址 | `var x int; fmt.Printf("%p", &x)` → 0xc000010230 |

------

## 7️⃣ **宽度与对齐**

| 占位符  | 说明                 | 示例                |
| ------- | -------------------- | ------------------- |
| `%6d`   | 宽度 6，右对齐       | `12` → "    12"     |
| `%-6d`  | 宽度 6，左对齐       | `12` → "12    "     |
| `%06d`  | 宽度 6，右对齐，补 0 | `12` → "000012"     |
| `%6.2f` | 宽 6，小数点 2 位    | `3.1415` → "  3.14" |
| `%.2f`  | 小数点 2 位          | `3.1415` → 3.14     |

------

## 8️⃣ **结构体 / map / slice**

| 占位符 | 说明           | 示例                       |
| ------ | -------------- | -------------------------- |
| `%v`   | 默认输出       | `[]int{1,2}` → [1 2]       |
| `%+v`  | 结构体带字段名 | `struct{X int}{1}` → {X:1} |
| `%#v`  | Go 语法表示    | `[]int{1,2}` → []int{1,2}  |
