```shell
//查看某个 Topic 的详细信息
bin/kafka-topics.sh --describe --topic <topic名称> --bootstrap-server <broker地址>
bin/kafka-topics.sh --describe --topic test-topic --bootstrap-server localhost:9092
```



#### 0.列出 Kafka 集群中的所有 Topic

```shell
bin/kafka-topics.sh --list --bootstrap-server <broker地址>
bin/kafka-topics.sh --list --bootstrap-server 192.168.169.130:9092
```



#### 1.查看特定topic的详细信息--describe

```shell
/opt/kafka_2.13-4.0.0/bin/kafka-topics.sh --bootstrap-server 192.168.169.130:9092 --describe --topic test-topic

```

#### 2.读取 Topic 内的最新消息--from-beginning

```shell
/opt/kafka_2.13-4.0.0/bin/kafka-console-consumer.sh --bootstrap-server 192.168.169.130:9092 --topic test-topic --from-beginning
```



#### 3.仅查看最新的 10 条消息--max-messages 10

```shell
/opt/kafka_2.13-4.0.0/bin/kafka-console-consumer.sh --bootstrap-server 192.168.169.130:9092 --topic my_topic --from-beginning --max-messages 10
```

#### 4.查看指定分区的数据

```shell
/opt/kafka_2.13-4.0.0/bin/kafka-console-consumer.sh --bootstrap-server 192.168.169.130:9092 --topic my_topic --partition 0 --offset 5
--partition 0：读取 my_topic 的 0 号分区
--offset 5：从 offset 5 开始读取
```

#### 5.查看当前 Topic 最新 Offset

```shell
/opt/kafka_2.13-4.0.0/bin/kafka-run-class.sh kafka.tools.GetOffsetShell --broker-list 192.168.169.130:9092 --topic my_topic --time -1
```
