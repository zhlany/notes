## 基本操作

### 1.基本查询语句

```mysql
 Select 列名    //查询的内容，选择哪列

 From 表名    //指定数据表

 Where     //查询时需要满足的条件

 Group by    //如何对结果进行分组

 Order by    //如何对结果进行排序

 Having    //查询时需要满足的第二条件

 Limit      //限定输出的查询结果
 
 
 //从一个或者多个表中获取数据
Select 表1.字段，表2.字段 from 表1，表2；
```



### 2.单表查询

```mysql
#去重
Select distinct 字段  from  表名；

#排序
Order by 字段名 [ASC | DESC]；//ASC升序排序，DESC降序排序

#分组
group by 字段；

#group by 与group_concat()函数一起使用
Select 字段1，字段2 group_concat(字段3) from 数据表 group by 字段3；

#限制查询
Select * from 表名 order by id ASC limit 3；
```



### 3.正则表达式查询

常用

```mysql
#^    特定字符开头
Where 字段 regexp'^php’;(php开头)

#$    特定字符结尾
regexp'php$';(php结尾)

#.    任意一个字符
regexp'P.';(包含P字符)

#[字符集合]
regexp'PAC';(包含PAC字符)

#[^字符集合]
regexp'^c-z';(包含c-z字符以外)

#|    或
regexp'PHP|java'; (包含PHP或java)

#*
regexp'j*a';(a字符前出现j字符的记录)

#+
regexp’j+a’;(a字符前至少1个j字符记录)

#{N}  出现N次
regexp'a{3}';(a字符出现3次)

#{M,N} 出现次数区间
regexp'a{3，5}';
```

例：

```mysql
#匹配指定字符中的任意一个  //[字符集合]

Select * from 表名 where 字段名 regexp '[PAC]';

#使用‘*’和‘+’匹配多个字符

Select * from 表名 where 字段名 regexp 'P*C';

Select * from 表名 where 字段名 regexp 'P+C';

#匹配以指定的字符开头和结尾的记录

Regexp ‘^L..y$’ ;   //L开头，y结尾
```

### 子查询

子查询就是select查询是另一个查询的附属。

```mysql
#带关键字IN的子查询
Select * from 表名 where use IN(Select user from 表名);

#带比较运算符的子查询
Select 字段 from 表名 where 字段2>=(…);

#带关键字exist的子查询,返回一个真假值，true | flash  。
Select 字段 from 表名 where exist(…条件判断);
#带关键字any的子查询,表示满足任意一个条件，即可通过。

#带关键字all的子查询
#表示满足所有条件。
```



### 合并查询

```mysql
#将多个select 的查询结果合并到一起。合并结果用关键字union 和 union all.
#Union    //合并结果值，并除去重复值。
Select user from 表1
Union
Select user from 表2;

#Union all    //合并所有结果值。
Select user from 表1
Union all
Select user from 表2;
```

## 比较难的查询

### 连接查询

#### 内连接查询

两个表或多个表以上的连接。

要求构成连接的每一部分的每个表的匹配，不匹配的行将被排除。

```mysql
Select 字段1，字段2 from 表1，表2 where 表1.字段3=表2.字段3；
```

#### 外连接查询

外连接使用outer join 关键字将两个表连接起来

```mysql
Select 字段 from 表名1 (left | right) join 表名2 on 表名1.字段1=表名2.属性名2；
```

#### 左外连接

左表所有数据 + 右表数据组合，右表没有的填Null

#### 右外连接

右表所有数据 + 左表数据组合，左表没有的填Null
