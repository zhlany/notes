### 数学函数

| ABS(x)              | 返回x的绝对值                                |
| ------------------- | -------------------------------------------- |
| Ceil(x),ceilin(x)   | 返回不小于x的最小正整数                      |
| Floor(x)            | 返回不大于x的最大正整数                      |
| Rand(x)             | 返回0~1的随机数                              |
| Sign(x)             | 返回参数作为-1,0或1的符号，符号取决于x的值   |
| Pi()                | 返回圆周率的值，默认小数位7位。              |
| Truncate(x,y)       | 返回数值x小数点后y位的值，截断时进行四舍五入 |
| Round(x)            | 返回离x最近的值                              |
| Pow(x,y),power(x,y) | 返回x的y乘方的结果值                         |
| Sqrt(x)             | 返回非负数x的二次方根                        |
| Exp(x)              | 返回e的x乘方后的值，（自然对数的低）         |
| Mod(x,y)            | 返回x除以y以后的余数                         |
| Log(x)              | 返回x的基数为2的对数                         |
| Log10(x)            | 返回x的基数为10的对数                        |
| Radians(x)          | 角度转换弧度                                 |
| Degrees(x)          | 返回参数x，该参数由弧度转换为度              |
| Sin(x)              | 正弦                                         |
| Asin(x)             | 反正弦                                       |
| Cos(x)              | 余弦                                         |
| Acos(x)             | 反余弦                                       |
| Tan(x)              | 反正切                                       |
| Atan(x),Atan2(x,y)  | 返回两个变量x及y的反正切                     |
| Cot(x)              | 余切                                         |

常用：

ABS(x)**函数**                //**绝对值**

Floor(x)**函数**              //  <=x**的最大正整数**

Rand(x)**函数**               // 0~1**的随机数**

PI()**函数**                       //**圆周率**

Truncate(x,y)**函数**       //**数值x小数点后y位的值**

Round(x)**函数和round(x,y)函数**  //**离x最近的整数**

Sqrt(x)**函数**                  //**求平方根**



### 系统信息函数

#### 获取MySQL版本号、连接数和数据库名的函数

VERSION()函数返回数据库的版本号；

CONNECTION_ID()函数返回服务器的连接数，也就是到现在为止MySQL服务的连接次数；

DATABASE()和SCHEMA()返回当前数据库名。



获取用户名函数

USER()、SYSTEM_USER()、SESSION_USER()、CURRENT_USER()和CURRENT_USER这几个函数可以返回当前用户的名称。

 

获取字符串的字符集合排序方式的函数

CHARSET(str)函数返回字符串str的字符集，一般情况下这个字符集就是系统的默认字符集；COLLATION(str)函数返回字符串str的字符排列方式。
