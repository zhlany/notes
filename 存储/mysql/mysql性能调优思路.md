# 性能调优思路

[TOC]

## 1.表设计不合理

- 字段不可分割
- 有主键，非主键字段依赖主键
- 非主键字段不能相互依赖
- 避免大表jion



## 2.分表

- 水平分割-数据结构相同时按照特定规则数量级分割
- 竖直分割-分割字段

## 3.配置优化

- my.cnf
- 最大连按数，max_connections
- 是否开启查询缓存，query_cache_size
- 查询排序时所能使用的缓冲区大小，read_buffer_size

## 4.偶发性访问高峰

- 缓存失效
- 业务活动



## 5.sql分析

- 定位慢sql语句，启动慢查询，mysqldumpslow分析

- 语句优化{

  1. 创建合理的索引
  2. 避免模糊查询
  3. where子句代替having子句
  4. 避免复杂的计算
  5. 业务层分析合理性

  }



## 6.存储过程

- 减少网路IO
- 安全性高
