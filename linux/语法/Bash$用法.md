# 📌 **Bash `$` 用法速查表**

| 类别             | 用法                       | 含义 / 说明                | 示例                        |
| ---------------- | -------------------------- | -------------------------- | --------------------------- |
| **变量取值**     | `$var` / `${var}`          | 获取变量值                 | `name="Tom"; echo $name`    |
| **命令替换**     | `$(command)` / ``command`` | 获取命令输出               | `today=$(date)`             |
| **特殊变量**     | `$?`                       | 上一个命令退出状态         | `echo $?`                   |
|                  | `$$`                       | 当前脚本/进程 PID          | `echo $$`                   |
|                  | `$0`                       | 当前脚本名                 | `echo $0`                   |
|                  | `$1, $2, ...`              | 脚本参数                   | `echo $1`                   |
|                  | `$@`                       | 所有参数（分开）           | `echo "$@"`                 |
|                  | `$*`                       | 所有参数（视为一个整体）   | `echo "$*"`                 |
|                  | `$#`                       | 参数个数                   | `echo $#`                   |
| **参数扩展**     | `${var:-default}`          | 若空或未定义，返回 default | `echo ${name:-"anonymous"}` |
|                  | `${var:=default}`          | 若空，设置 var=default     | `echo ${name:="anonymous"}` |
|                  | `${var:+alt}`              | 若非空，返回 alt           | `echo ${name:+filled}`      |
|                  | `${var:pos:len}`           | 字符串截取                 | `echo ${name:1:3}`          |
|                  | `${var/pat/rep}`           | 替换第一个匹配             | `echo ${name/o/O}`          |
|                  | `${var//pat/rep}`          | 替换全部匹配               | `echo ${name//o/O}`         |
| **数组相关**     | `${arr[0]}`                | 获取数组元素               | `arr=(a b); echo ${arr[0]}` |
|                  | `${arr[@]}`                | 获取所有元素               | `echo ${arr[@]}`            |
|                  | `${#arr[@]}`               | 数组长度                   | `echo ${#arr[@]}`           |
| **算术扩展**     | `$((expression))`          | 计算表达式                 | `n=$((1+2))`                |
| **转义 `$`**     | `\$`                       | 输出 `$` 字符              | `echo \$HOME`               |
| **引号中的 `$`** | 双引号 `"..."`             | 会解析变量                 | `echo "$HOME"`              |
|                  | 单引号 `'...'`             | 不解析变量                 | `echo '$HOME'`              |

------

💡 **记忆技巧**

1. `$var` → 普通变量
2. `${var...}` → 参数扩展/操作
3. `$(command)` → 命令替换
4. `$# $@ $*` → 脚本参数
5. `$$ $? $0` → 系统/脚本信息
