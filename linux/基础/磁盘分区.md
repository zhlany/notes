# 常用记录：

```shell
# 
lsblk -l
# 显示文件系统类型和 UUID
lsblk -f
lsblk -f -o NAME,FSTYPE,SIZE,UUID,MOUNTPOINT
# 查看磁盘使用
df -h 
# 查看目录大小
du -sh <目录>
# 显示磁盘 UUID 和文件系统
blkid
# 创建文件系统
mkfs.ext4 /dev/sda1
# 挂载分区
mount /dev/sda1 /mnt
# 卸载分区
umount /mnt
# 删除分区
fdisk /dev/nvme0n1
# 清除分区表签名（强力）
wipefs /dev/sda
# 使用 dd 覆盖前 10MB（最常用）覆盖磁盘头部会破坏分区表（足够清除所有分区信息）：
dd if=/dev/zero of=/dev/sda bs=1M count=10
```



# Linux 磁盘与分区命令速查表

| 类别         | 命令                                   | 功能                     | 示例                                                         |
| ------------ | -------------------------------------- | ------------------------ | ------------------------------------------------------------ |
| 查看磁盘     | `lsblk`                                | 列出块设备及挂载点       | `lsblk -f`                                                   |
| 查看分区表   | `fdisk -l`                             | 打印磁盘分区表（root）   | `sudo fdisk -l`                                              |
| 查看 UUID    | `blkid`                                | 显示磁盘 UUID 和文件系统 | `sudo blkid`                                                 |
| 查看磁盘使用 | `df -h`                                | 查看分区空间使用         | `df -h`                                                      |
| 查看目录大小 | `du -sh <目录>`                        | 查看目录占用空间         | `du -sh /home`                                               |
| 查看分区信息 | `parted -l`                            | 查看磁盘分区             | `sudo parted -l`                                             |
| 查看设备     | `ls /dev/sd*`                          | 查看磁盘设备             | `/dev/sda /dev/sdb ...`                                      |
| 查看分区     | `cat /proc/partitions`                 | 显示分区信息             | `cat /proc/partitions`                                       |
| 分区操作     | `fdisk /dev/sda`                       | MBR 分区操作             | `sudo fdisk /dev/sda`                                        |
| 分区操作     | `parted /dev/sda`                      | GPT 分区操作             | `sudo parted /dev/sda`                                       |
| 创建文件系统 | `mkfs.ext4 /dev/sda1`                  | 创建 ext4 文件系统       | `sudo mkfs.ext4 /dev/sda1`                                   |
| 挂载分区     | `mount /dev/sda1 /mnt`                 | 临时挂载                 | `sudo mount /dev/sda1 /mnt`                                  |
| 卸载分区     | `umount /mnt`                          | 卸载挂载点               | `sudo umount /mnt`                                           |
| 永久挂载     | 编辑 `/etc/fstab`                      | 配置开机自动挂载         | `/dev/sda1 /data ext4 defaults 0 2`                          |
| RAID         | `mdadm`                                | 软件 RAID 管理           | `sudo mdadm --create /dev/md0 --level=1 --raid-devices=2 /dev/sda /dev/sdb` |
| LVM          | `pvcreate /dev/sda1`                   | 创建物理卷               | `sudo pvcreate /dev/sda1`                                    |
| LVM          | `vgcreate vg01 /dev/sda1`              | 创建卷组                 | `sudo vgcreate vg01 /dev/sda1`                               |
| LVM          | `lvcreate -L 10G -n lv01 vg01`         | 创建逻辑卷               | `sudo lvcreate -L 10G -n lv01 vg01`                          |
| LVM          | `mount /dev/vg01/lv01 /mnt`            | 挂载逻辑卷               | `sudo mount /dev/vg01/lv01 /mnt`                             |
| I/O 查看     | `iostat -x 1`                          | 实时磁盘 I/O             | `iostat -x 1`                                                |
| 文件系统类型 | `lsblk -o NAME,SIZE,FSTYPE,MOUNTPOINT` | 查看文件系统和挂载点     | `lsblk -o NAME,SIZE,FSTYPE,MOUNTPOINT`                       |
| 文件系统空间 | `df -Th`                               | 查看文件系统类型和使用   | `df -Th`                                                     |
