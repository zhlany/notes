# 📌 Bash 条件判断符号一张表

| 分类           | 符号          | 含义                     |
| -------------- | ------------- | ------------------------ |
| **文件测试**   | `-e FILE`     | 文件存在                 |
|                | `-f FILE`     | 普通文件                 |
|                | `-d FILE`     | 目录（directory）        |
|                | `-s FILE`     | 文件非空(size > 0）      |
|                | `-r FILE`     | 可读                     |
|                | `-w FILE`     | 可写                     |
|                | `-x FILE`     | 可执行                   |
|                | `-L FILE`     | 符号链接                 |
|                | `-b FILE`     | 块设备（block device）   |
|                | `-c FILE`     | 字符设备（char device）  |
|                | `-p FILE`     | 管道（pipe）             |
|                | `-S FILE`     | Socket                   |
| **字符串判断** | `-z STR`      | 字符串长度为 0           |
|                | `-n STR`      | 字符串长度非 0           |
|                | `STR = STR2`  | 字符串相等               |
|                | `STR != STR2` | 字符串不等               |
|                | `STR < STR2`  | 字典序小于（仅 `[[ ]]`） |
|                | `STR > STR2`  | 字典序大于（仅 `[[ ]]`） |
| **整数比较**   | `-eq`         | 等于                     |
|                | `-ne`         | 不等于                   |
|                | `-gt`         | 大于                     |
|                | `-ge`         | 大于等于                 |
|                | `-lt`         | 小于                     |
|                | `-le`         | 小于等于                 |
| **逻辑运算**   | `!`           | 取反                     |
|                | `-a`          | AND（旧写法，不推荐）    |
|                | `-o`          | OR（旧写法，不推荐）     |
|                | `&&`          | 与（推荐）               |
|                | \|\|          | 或（推荐）               |

------

# 📌 最推荐的写法

```
[[ 条件1 && 条件2 ]]
```

例：

```
if [[ -f "$file" && -s "$file" ]]; then
```

# 🐧 Bash `[ ]` vs `[[ ]]` 功能对比表

| 功能           | `[ ... ]`                 | 示例                            | `[[ ... ]]`   | 示例                   |
| -------------- | ------------------------- | ------------------------------- | ------------- | ---------------------- |
| **变量比较**   | `=` / `!=`                | `[ "$a" = "1" ]`                | `=` / `!=`    | `[[ $a == 1 ]]`        |
| **逻辑运算**   | `-a` / `-o` / `!`         | `[ "$a" -gt 0 -a "$b" -lt 10 ]` | `&&` / `      |                        |
| **数字比较**   | `-eq -ne -gt -ge -lt -le` | `[ "$a" -gt 5 ]`                | 同 `[ ]`      | `[[ $a -le 10 ]]`      |
| **字符串比较** | 字典序不支持 `< >`        | `[ "$str1" = "$str2" ]`         | 支持 `< >`    | `[[ $str1 < $str2 ]]`  |
| **通配符匹配** | 不支持                    | `[ "$file" = *.txt ]` 可能出错  | 支持          | `[[ $file == *.txt ]]` |
| **正则表达式** | 不支持                    | —                               | 支持 `=~`     | `[[ $str =~ ^abc ]]`   |
| **空值处理**   | 必须加引号防止报错        | `[ "$var" = "" ]`               | 自动安全      | `[[ $var == "" ]]`     |
| **可移植性**   | 高（POSIX shell 支持）    | `[ ... ]`                       | 仅 Bash / Zsh | `[[ ... ]]`            |
