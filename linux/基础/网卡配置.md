# 网卡配置

子网掩码计算

```tex
192.168.1.100/24

# /24 表示 IP 地址中前 24 位 是网络位。
# IP 地址共 32 位，所以剩余 8 位 是主机位。

二进制：11111111.11111111.11111111.00000000
十进制：255       .255       .255       .0

每增加 1 位网络位，子网掩码的最后一个字节就增加 128、64、32… 等值（对应二进制位的权重）。
/24 -> 255.255.255.0
/25 -> 255.255.255.128
/26 -> 255.255.255.(128+32)
...

每减少 1 位网络位，对应的十进制减少值依次是：1、2、4、8、16、32、64、128
/24 -> 255.255.255.0
/23 -> 255.255.(255-2^0).0
/22 -> 255.255.(255-2^1).0
```



## 临时配置（重启失效）

### ifconfig（传统方式）

```shell
ifconfig
ip addr show

ifconfig eth0 192.168.1.100 netmask 255.255.255.0
ifconfig eth0 up/down # 启用/禁用

# 添加多个IP
ifconfig eth0:0 192.168.1.101
```

### IP（推荐）

```sh
ip link show
ip addr show

# 配置IP
ip addr add 192.168.1.100/24 dev eth0
ip addr del 192.168.1.100/24 dev eth0

# 设置网卡状态
ip link set eth0 up
ip link set eth0 down

ip route add default via 192.168.1.1
echo "nameserver 8.8.8.8"|tee /etc/resolv.conf
echo "nameserver 114.114.114.114"|tee -a /etc/resolv.conf
```

## 永久配置（配置文件）

### 通用方法（/etc/network/interfaces）

```bash
# /etc/network/interfaces
auto eth0
iface eth0 inet static
    address 192.168.1.100
    netmask 255.255.255.0
    gateway 192.168.1.1
    dns-nameservers 8.8.8.8
```

```bash
vi /etc/sysconfig/network-scripts/ifcfg-ens33

//配置静态IP，添加
BOOTPROTO="static"          # 改为静态 IP（或使用 "none"）
IPADDR=192.168.1.100       # 静态 IP 地址（根据实际网络填写）
NETMASK=255.255.255.0      # 子网掩码
GATEWAY=192.168.1.1        # 默认网关（通常为路由器 IP）
DNS1=8.8.8.8               # 主 DNS（已存在，无需修改）
DNS2=8.8.4.4               # 备用 DNS（已存在，无需修改）
```



### DNS配置

```visual basic
# 编辑resolv.conf
vi /etc/resolv.conf
# 添加
nameserver 8.8.8.8
nameserver 8.8.4.4
```

### 网络管理

```shell
# 启用服务
systemctl enable systemd-networkd
systemctl start systemd-networkd

# 配置文件
# /etc/systemd/network/10-eth0.network
[Match]
Name=eth0

[Network]
Address=192.168.1.100/24
Gateway=192.168.1.1
DNS=8.8.8.8
```

## 网络工具

### 路由跟踪

```sh
# 测试连通性
ping google.com

# 查看路由表
route -n
ip route show

# 网络统计
netstat -tulnp
ss -tulnp

# 查看网络接口详情
ethtool eth0

# 跟踪路由
traceroute google.com
mtr google.com
```

### 故障排查

```shell
# 检查配置
ip addr show
ip route show

# 查看日志
journalctl -u systemd-networkd
journalctl -u NetworkManager

# 测试网络
ping -c 4 8.8.8.8
ping -c 4 google.com
nslookup google.com

# 重启网络服务
systemctl restart networking      # Ubuntu传统
systemctl restart NetworkManager  # NetworkManager
systemctl restart systemd-networkd # systemd-networkd
```
